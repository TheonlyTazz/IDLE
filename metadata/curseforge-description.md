# Idle Cinematics

Idle Cinematics turns quiet moments into smooth cinematic views. After a configurable period without keyboard or
mouse input, the camera begins moving around your player with collision-aware orbit and drift shots. Any input returns
you to normal gameplay immediately.

Inspired by [AFK Cinematics](https://www.curseforge.com/minecraft/mc-mods/afk-cinematics) for Fabric. Idle Cinematics
is a fresh implementation for NeoForge.

## Features

- Automatic activation after configurable inactivity
- Smooth orbit and elevated drift camera paths
- Collision-aware camera positioning
- Immediate exit on keyboard or mouse input
- Optional HUD hiding during cinematic mode
- Manual start/stop and enable/disable keybindings
- Configurable timeout, speed, path mode, and transition smoothing
- Restores the previous camera perspective when the cinematic ends

## Controls

- `F8`: Enable or disable automatic activation
- `F9`: Start or stop cinematic mode immediately

## Requirements

- Minecraft 26.1.2
- NeoForge
- Client-side installation

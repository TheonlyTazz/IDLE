# Idle Cinematics 1.3.0

Adds the versioned preset API, semantic camera rig, critically damped transitions, bounded scene analysis,
camera-volume collision, new context-aware scenes, the explicit AFK lifecycle, layered countdown/timer HUD,
transactional settings pages, optional FPS/FOV/audio profiles, crash recovery, and compatibility diagnostics.

Existing configuration keys remain in place and all option-changing profiles are disabled by default.

# Idle Cinematics 1.2.0

- Added a public, versioned landmark compatibility API for add-ons.
- Added bounded discovery of registered landmarks through block entities in already-loaded client chunks.
- Added landmark orbit, reveal, and crane scenes with collision-aware planning.
- Added optional built-in identifiers for prominent magic and technology landmarks in FTB Evolution 2,
  FTB Unstable 6, and FTB Evolution 1.21.1.
- Added landmark details to the debug overlay.

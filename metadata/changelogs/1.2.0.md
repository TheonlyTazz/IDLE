# Idle Cinematics 1.2.0

## Landmark scenes and compatibility

- Added a public, versioned landmark compatibility API for add-ons.
- Added bounded discovery of registered landmarks through block entities in already-loaded client chunks.
- Added landmark orbit, reveal, and crane scenes with collision-aware planning.
- Added optional built-in identifiers for prominent magic and technology landmarks.
- Added landmark details to the debug overlay.

## Modpack integration

- Added an optional KubeJS startup event for pack-defined landmarks and parameterized landmark scenes.
- Added extensive Java add-on, landmark compatibility, KubeJS, and scene cookbook documentation.

## Scene settings and fixes

- Reworked scene settings into one searchable, scrollable list with category separators, category-wide toggles,
  and individual controls for built-in and addon scenes.
- Combined time-specific compositions under one Celestial Scenes category.
- Replaced the redundant nearby-mob switch with the Entity Scenes controls and skipped entity scanning when no
  enabled scene needs it.
- Preserved legacy scene-pool and nearby-entity choices by migrating them into individual scene selections.
- Fixed landmark-only configurations incorrectly falling back to a player orbit.
- Fixed solid landmark subjects being rejected as obstructions during camera planning.

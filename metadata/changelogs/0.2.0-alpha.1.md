# Idle Cinematics 0.2.0-alpha.1

- Adds thirty-four independently composed camera presets across player, landscape, entity, cave, Nether, End, sunrise, daytime, sunset, and night pools.
- Adds context-aware shot selection based on sky visibility, surrounding space, underground location, time of day, and nearby living entities.
- Adds smooth transitions between shots and avoids immediately repeating the same composition.
- Adds an in-game settings screen through the NeoForge Mods menu and the F10 key.
- Adds configurable shot selection, shot duration, camera distance, and nearby-entity framing.
- Detects enclosed caves at any elevation, keeps the camera close, and cuts between cave shots more frequently.
- Introduces a tagged preset registry, immutable scene snapshots, weighted direction, and reusable shot-plan API for future preset expansion.
- Adds an optional on-screen and logged preset debugger showing the active pool and preset ID.

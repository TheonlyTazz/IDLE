# Idle Cinematics 1.1.0

This is the complete first feature release after 1.0.x, available for NeoForge on Minecraft 26.1.2 and 1.21.1.

## Cinematic director

- Adds a semantic camera rig with consistent distance controls and critically damped transitions.
- Adds cut, damped, match-move, and continuous-orbit transitions.
- Adds bounded eight-direction scene analysis, scored entity subjects, and context-aware scene selection.
- Adds elevated, breathing, helical, isometric, hero, figure-eight, crane, parallax, expedition, terrain,
  living-subject, cave, Nether, End, weather, and celestial compositions.
- Adds five-ray camera-volume collision, visibility validation, bounded reselection, and a safe player fallback.
- Keeps the detached camera independent from Minecraft's perspective option and renders only required subjects.

## AFK lifecycle and interface

- Adds an explicit AFK lifecycle with a cancellable countdown, forced activation, instant input cleanup, chat
  handling, world-change invalidation, settings suspension, and configurable focus-regain behavior.
- Adds dedicated countdown, elapsed-time, and diagnostic overlay layers without canceling unrelated mod overlays.
- Rebuilds settings as vanilla-style full-screen category pages with transactional Apply/Cancel semantics,
  confirmation dialogs, scoped resets, responsive resizing, and a scrollable per-scene selector.
- Allows every built-in and addon scene to be enabled independently.

## Optional profiles and recovery

- Adds opt-in temporary FPS, cinematic FOV, and master-volume profiles.
- Restores only values still owned by IDLE and repairs stale profile state after an interrupted client session.
- Leaves all option-changing profiles disabled by default.

## Addon API and compatibility

- Adds the versioned typed preset API used by IDLE's built-ins and third-party addons.
- Adds immutable registration, duplicate-ID validation, injected random generators, and addon documentation.
- Keeps renderer integration targeted: no terrain/frustum graph mixins and no blanket entity-render override.
- Adds automated coverage for damping, transitions, collision, selection, lifecycle, settings drafts, profiles,
  recovery, and per-preset preferences.

Existing TOML keys remain in place. New defaults use a top-left timer without the `AFK ·` title, and returning
focus to the game no longer exits cinematic mode unless that option is enabled.
